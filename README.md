# DataverseToCode assets

Pictures and videos for the [DataverseToCode](https://marketplace.visualstudio.com/items?itemName=CloudFish.dataverse-to-code) VS Code extension's Marketplace page.

- `readme/`: the screenshots and animation the extension's README shows.
- `video/tour-short.mp4`: a 4-minute tour. `video/tour-long.mp4`: the full walkthrough (10 minutes).

Everything here was recorded on a demo project (Contoso Projects) with no real environment behind it.
